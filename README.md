# BotArena

**BotArena** — учебно-исследовательская платформа на Python для соревнований автономных программируемых ботов на клеточной арене. Проект разрабатывается для сравнения алгоритмов управления в воспроизводимых условиях и подготовки конференционной работы.

## Текущее состояние

**26 ноября 2026 года:** подготовлена и локально проверена первая **консольная версия 0.1.0**. Графический интерфейс Pygame **ещё не реализован**. Код и файлы из этого комплекта **не отправлены автоматически на GitHub**.

В среде подготовки (Python 3.13.5) пройдены 33 автоматических теста. Также выполнен технический прогон из 540 матчей на 90 фиксированных картах; сохранён исходный CSV. Это проверка работы программы, а не окончательное доказательство гипотезы и не проверка на компьютере команды.

## Что работает в этой версии

- Генерация воспроизводимых карт 12×12, 10 ресурсов и заданная плотность препятствий.
- Проверка достижимости ресурсов из обеих стартовых клеток.
- Два бота, 100 раундов, поочерёдные ходы, сбор ресурсов, подсчёт очков.
- Стратегии `Random`, `Greedy` и `A*` с одинаковым доступом к состоянию карты.
- Отдельный игровой движок без Pygame, текстовый просмотр поля в терминале.
- JSON-протокол матча, CSV-таблица серии, автоматические тесты.

**Планируется:** графический интерфейс Pygame, управление воспроизведением, визуальные результаты экспериментов, улучшенное подключение пользовательских стратегий. Не реализованы сетевые соревнования, 3D и машинное обучение.

## Первый запуск

Требуется **Python 3.11 или новее**. Команды приведены для PowerShell в корне проекта.

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m botarena match --a greedy --b astar --seed 42 --view --delay 0.1
```

Один матч с сохранением полного протокола:

```powershell
.\.venv\Scripts\python.exe -m botarena match --a random --b astar --seed 42 --json results/match.json
```

Техническая серия (по 30 карт для каждой плотности, 540 матчей):

```powershell
.\.venv\Scripts\python.exe -m botarena batch --maps 30 --csv results/experiment.csv
```

Папка `results/` исключена из Git: результаты надо осознанно отбирать перед публикацией. Инструкция пока не проверялась в вашей конкретной версии Windows; запуск и окружение нужно подтвердить локально.

## Правила игры

Поле 12×12; два бота `A` и `B`; десять ресурсов по одному очку. Доступны команды `UP`, `DOWN`, `LEFT`, `RIGHT`, `WAIT`. Нельзя пересекать стену, границу или занятую соперником клетку. В чётных раундах первым ходит A, в нечётных — B. Завершение при сборе всех ресурсов или после 100-го раунда. Победитель определяется по очкам.
