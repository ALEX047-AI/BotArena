# Технический прогон BotArena — 26 ноября 2026 года

**Цель:** проверить возможность воспроизводимого пакетного запуска, записи протокола и базовую работоспособность движка; это **не** финальная научная интерпретация эффективности стратегий.

## Окружение и версия

- Python 3.13.5 в тестовой среде Linux (не компьютер участников).
- Пакет BotArena 0.1.0, правила 0.1, схема протокола 1.
- Для игрового ядра нет внешних runtime-зависимостей.
- Исходный файл: [SMOKE_BATCH_540_2026-11-26.csv](SMOKE_BATCH_540_2026-11-26.csv).

## Запуск и наблюдения

Команды в среде подготовки (из корня проекта):

```bash
PYTHONPATH=src python -m pytest -q
PYTHONPATH=src python -m botarena match --a greedy --b astar --seed 42 --json results/match.json
PYTHONPATH=src python -m botarena batch --maps 30 --csv research/SMOKE_BATCH_540_2026-11-26.csv
```

- **33 теста пройдены**, ошибок 0.
- Техническая серия: **540 матчей**, **90 различных карт** (30 seed на каждую из трёх плотностей), в каждой паре перестановка сторон.
- По записанным строкам: **0 `BOT_ERROR` и 0 `INVALID_ACTION`**. Это не исключает других ошибок и не является оценкой качества стратегии.
- Значения seed: от 1000 до 1029 для каждой плотности; правила и алгоритмы фиксированы в файле CSV.
- Отдельный запуск Greedy vs A* на карте с `seed=42` завершился за 16 раундов, счёт A 7, B 3 (необобщаемый одиночный пример).

## Ограничения

Результат не прошёл независимую проверку человеком, графическая версия отсутствует; испытания на Windows/VS Code участников ещё не выполнены. Нельзя использовать данный файл как доказательство переносимости на реальную робототехнику или окончательного превосходства одного алгоритма. При изменении генератора/правил сравнение требует нового набора запусков.
