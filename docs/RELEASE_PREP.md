# Подготовка первой публикации BotArena

Файлы подготовлены **локально**. Публикация на GitHub ещё не подтверждена.

1. Проверить, что открыта нужная папка с правильным `origin` (`git remote -v`).
2. Сравнить существующие README/документы с файлами комплекта, особенно если репозиторий уже содержит изменения.
3. Запустить `python -m pytest -q` и один матч на компьютере команды.
4. Проверить `git status` и `git diff --stat`, отсутствие `.env`, ключей, временных файлов, папки `.venv` и закрытых заметок.
5. Убедиться, что в публичном репозитории нет содержимого `internal/` и чужой истории `.git`.
6. Коммитить только проверенные изменения. Лицензия не выбрана.

Пример после проверки:

```powershell
git add README.md pyproject.toml .gitignore src tests examples docs research
git diff --cached --stat
git commit -m "Добавлено консольное ядро BotArena и документация v0.1"
git push origin main
```

Команды показаны как **пример** для случая, если вы действительно работаете в `main` и ваша команда договорилась публиковать в неё. При работе через отдельную ветку сначала создайте её и отправляйте PR.
