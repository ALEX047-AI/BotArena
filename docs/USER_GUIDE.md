# Руководство пользователя BotArena v0.1.0

**Состояние:** работает консольный движок и текстовый просмотр арены. Графическая версия на Pygame пока в разработке.

## Требования

Python 3.11+; интернет не требуется для самой игры. Для первой установки `pytest` и упаковочного окружения может потребоваться доступ к Python-пакетам. В среде подготовки код проверен с Python 3.13.5.

## Запуск в VS Code / PowerShell

Откройте терминал в **корне нужного репозитория**, где находится `pyproject.toml`:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m botarena match --a greedy --b astar --seed 42 --view --delay 0.1
```

Если `py` не найден, замените `py` на `python`, предварительно проверив `python --version`.

Для быстрого запуска без установки пакета допускается в корне репозитория:

```powershell
$env:PYTHONPATH = "src"
python -m botarena match --a greedy --b astar --seed 42
```

## Игра

`A`, `B` — автономные боты, `#` — стена, `*` — доступный ресурс. В каждом раунде оба бота выбирают действие. При входе на ресурс начисляется один балл. В конце матча выводятся счёт, победитель и причина завершения.

## Протокол и пакетная серия

```powershell
python -m botarena match --a random --b astar --seed 42 --json results/match.json
python -m botarena batch --maps 3 --csv results/experiment.csv
```

Команда `batch --maps 30` запускает 540 матчей: три пары алгоритмов × три плотности стен × 30 карт × две перестановки сторон. Это может использоваться для исследования только с учётом ограничений методики и версии генератора.

## Типичные проблемы

- `No module named botarena`: пакет не установлен, либо не задан `PYTHONPATH=src`.
- `No module named pytest`: установите dev-зависимости, либо `python -m pip install pytest`.
- Пустое поле результата: попробуйте запуск `match --view`; графика Pygame в этой версии отсутствует.
- Файл CSV не появляется в Git: каталог `results/` игнорируется намеренно.

Запуск на конкретном компьютере команды ещё должен быть проверен после копирования файлов.
