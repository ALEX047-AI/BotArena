# Командная строка BotArena v0.1.0

После установки `pip install -e .` доступны команды `python -m botarena` (или `botarena`, если консольные скрипты добавлены в PATH).

## Один матч

```bash
python -m botarena match --a random --b astar --seed 42 --seed-a 101 --seed-b 202 --density 0.1 --rounds 100 --json results/match.json
```

| Аргумент | Назначение | По умолчанию |
|---|---|---|
| `--a`, `--b` | `random`, `greedy`, `astar` | `greedy`, `astar` |
| `--seed` | Seed генерации карты | `42` |
| `--seed-a`, `--seed-b` | Независимые seed контроллеров | `101`, `202` |
| `--density` | Доля стен в диапазоне 0..1 | `0.1` |
| `--rounds` | Ограничение числа раундов | `100` |
| `--json` | Сохранить JSON-протокол | не сохранять |
| `--view` | Показывать карту в консоли по раундам | выключено |
| `--delay` | Задержка между кадрами в секундах (только с `--view`) | `0.1` |

## Серия

```bash
python -m botarena batch --maps 30 --first-seed 1000 --rounds 100 --csv results/experiment.csv
```

Генерируются три пары стратегий (Random–Greedy, Random–A*, Greedy–A*) при плотностях стен 10, 20, 30%. Каждая пара играет два матча с перестановкой сторон на той же карте. `--maps` означает количество карт **на одну плотность**. Вывод CSV имеет кодировку UTF-8 с BOM для удобства открытия в Excel.

## Отложенный функционал

Пока нет команд сетевой игры, Pygame-окна, изолированного запуска произвольных файлов и обучения нейросети.
